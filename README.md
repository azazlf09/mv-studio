# MV Studio

> 两步生成 MV 提示词 · 服化道定妆 + 专业分镜，输出可直接复制到 Midjourney / 即梦 / 可灵 / Veo

## 它是什么

MV Studio 是一款本地 Windows 桌面 APP，专门帮你完成 MV 拍摄/AI 视频前期的两件事：

1. **第一步 · 服化道方案**：输入歌词 + 风格元素 + 角色照 → AI 生成 3 个完整定妆方案（妆容、发型、服装、配饰、场景氛围、配色），每个方案带一段 200-400 字的密集中文 AI 出图提示词，可直接复制到任意图像生成模型。

2. **第二步 · 分镜提示词表**：基于第一步的成果 + 你上传的定妆参考图 → AI 按歌词逐句生成专业分镜，每条含：景别、角度、运镜方式、视角、参考图、画面描述、对应歌词。每条都按可直接喂给视频生成模型的固定格式输出。

## 安装

下载 `MV-Studio-Setup-x.x.x.exe`，双击安装。

**首次启动会触发 Windows SmartScreen 警告**（因为安装包没做代码签名）：点「更多信息」→「仍要运行」即可。

## 首次使用

启动后会自动进入 Welcome 引导页：

1. **试用示例项目**（推荐）—— 一首虚构原创歌词《夜色信号》，包含 3 个预填定妆方案 + 12 条预填分镜，30 秒内看到完整效果，**无需任何配置**
2. **新建我的 MV 项目** —— 从空白开始，需要先配置 AI 服务（见下文）
3. **打开本地项目** —— 加载之前保存的项目

## AI 服务配置（自己创建项目时需要）

MV Studio 支持多种 AI 服务，推荐选择 **Claude Code CLI**（零配置、最稳）。

### 选项 A · Claude Code CLI（推荐）

如果你已经在用 Claude Code 命令行：MV Studio 会自动调用你登录好的 `claude` 命令，**不需要任何 API Key**，按你的 CC 订阅计费。

如果还没装：

```powershell
npm install -g @anthropic-ai/claude-code
claude login
```

完成后重启 APP，Welcome 页会显示 ✓ 已检测到。

### 选项 B · API Key（DeepSeek / 通义 / OpenAI / Gemini 等）

在 APP 内打开「设置」，选择对应供应商预设，填入 API Key 即可。已内置 13 个供应商预设。

⚠ 注意：DeepSeek 不支持图像输入，第一步无法用角色照分析气质。如需图像分析推荐 Claude Code CLI / 通义千问 vl / Kimi vision。

## 输出格式

第二步生成的每条分镜都遵循固定文本规范，可直接复制到视频生成 AI：

```
景别角度:全景，侧拍，运镜视角:侧向匀速跟拍，第三人称视角，
服装场景参考图1，人物参考图2，演唱音频1，
【夕阳西下的教室内，少女坐在靠窗的课桌前，背对镜头微微侧头…】，
歌词:"不敢回看"
```

支持单条复制、全部一键复制、TXT/MD 导出。

## 项目数据

每个 MV 项目是一个文件夹，结构：

```
你的MV项目/
  project.json     ← 所有数据（歌词、方案、分镜）
  refs/
    character/     ← 角色参考照
    costume/       ← 定妆/服装参考照
```

可以直接复制/打包项目目录给协作者。

## 常见问题

### 启动后调用 AI 失败

去右下角 🖥 调试面板（如果默认隐藏，按 `Ctrl + \`` 唤起）查看具体错误。常见情况：
- **未检测到 Claude Code CLI** → 跑 `claude --version` 验证是否安装
- **5xx 上游错误** → 中转商问题，换个供应商或稍等
- **JSON 解析失败** → 重新点一次生成（模型偶尔会输出格式异常）

### 我想把调试面板常驻显示

设置 → 勾选「显示开发调试面板」。

### 项目存哪里

默认在你系统的「文档」目录下。在设置里可以改默认存储路径。

### 卸载会删数据吗

不会。APP 卸载只删程序文件；你的项目目录和 APP 设置（包括加密保存的 API Key）会保留。如需彻底清除，手动删 `%APPDATA%\MV Studio\`。

## 给开发者

```bash
npm install
npm run dev          # 开发模式（HMR）
npm run build        # 编译
npm run package      # 打 NSIS 安装包到 release/
```

DevTools 默认关闭。需要时按 `Ctrl + Shift + I` 打开，或设环境变量 `MV_DEVTOOLS=1` 启动让它自动开。
